# Java Library System

My first Java project, built while transitioning from C++ to Java.

A simple console-based library management system written in pure Java, with no external dependencies.

## Features

- Register books
- Delete books
- Register users
- Borrow books
- Return books
- List books

## Concepts

- Object-Oriented Programming
- Java Collections Framework (`HashMap`)
- Exception Handling

## How to Run

Requires JDK 17 or newer.

### IntelliJ IDEA

1. Clone the repository
2. Open the project folder in IntelliJ
3. Run the `Main` class

### Command Line

```bash
git clone https://github.com/n1c053k/java-library-system.git
cd java-library-system
javac -d out -sourcepath src src/Main.java
java -cp out Main
```
